# 7-Day South Indian Meal Plan Prompt

> A reusable, structured prompt for generating a full week of South Indian meals.

 ![License: MIT](https://img.shields.io/badge/License-MIT-green.svg)

## Overview

A **prompt-engineering** exercise. `meal_plan_prompt.md` contains a structured prompt (role, constraints, required format) that reliably makes an LLM return a 7-day South Indian meal plan covering every meal of the day. Copy it into ChatGPT, Claude or any LLM.

## Project structure

```text
.
└── meal_plan_prompt.md   # the prompt
```

## Usage

Open `meal_plan_prompt.md`, copy the prompt into your LLM of choice and adjust the constraints (diet, calories, region) as needed.
