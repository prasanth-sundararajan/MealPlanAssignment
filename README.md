# 7-Day South Indian Meal Plan Prompt

## What this project is

This assignment is a reusable prompt, not a meal-planning program. The prompt is in [`meal_plan_prompt.md`](./meal_plan_prompt.md). It tells an AI chat tool to create a balanced, vegetarian South Indian meal plan for seven days, with breakfast, lunch, snack, and dinner, portion sizes, and safety guardrails.

## What to do

1. Open `meal_plan_prompt.md` and edit only the **Editable details** block at the top, such as activity level, allergies, dislikes, location, cooking time, and number of people.
2. Copy the prompt into any AI chat tool and run it. Ollama is optional; the assignment does not require a particular AI model.
3. Check that the answer has one table with Monday through Sunday and exactly four meals per day (28 meal rows), named South Indian dishes, and portions.
4. Test that the prompt is reusable by changing only the editable details. For example, use a real allergy if applicable, or a clearly marked test allergy that is safe for the person. Check that the answer respects it.
5. Correct any gaps in the prompt, then save the final file.
6. Push the required prompt file to GitHub and share its link as the assignment requests.

## Important

An AI-generated plan is a general draft, not dietary advice. A qualified dietitian should provide personal nutrition guidance.

## Task completed

The prompt describes the AI's role, the person the plan is for, dietary and safety rules, the seven-day meal requirements, and the table format. It keeps personal details together so they can be changed without rewriting the whole prompt.

## Beginner task question

**Can you write a reusable prompt that asks an AI to create a healthy seven-day vegetarian South Indian meal plan, with breakfast, lunch, snack, dinner, and portion sizes for every day?**

Test your prompt twice. On the second run, change only the editable details and check that the AI still follows the meal and table rules.
